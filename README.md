# TFE Docs — демонстрационный веб-интерфейс

Статический frontend-прототип корпоративного документооборота The FLOX Entertainment.

## Возможности
- Обзор, список, поиск и фильтрация документов.
- Шаблоны: пустой документ, приказ, служебная записка, протокол.
- Форматирование текста, списки, выравнивание, таблицы.
- Редактирование реквизитов и выбор согласующего.
- Черновики и демонстрационная отправка на согласование.
- Предпросмотр A4, печать и сохранение в PDF через браузер.
- Локальное сохранение в localStorage, адаптивный интерфейс, PWA-оболочка.

## Публикация на GitHub Pages
1. Создайте репозиторий GitHub.
2. Загрузите все файлы архива в корень репозитория.
3. Откройте Settings → Pages.
4. Выберите Deploy from a branch.
5. Укажите ветку `main` и папку `/ (root)`, нажмите Save.
6. Откройте адрес Pages после публикации.

## Важные ограничения
Это демонстрационный frontend, а не production-система. Данные хранятся только в localStorage конкретного браузера и не синхронизируются между устройствами. Авторизация, реальные роли и права доступа, серверное хранилище файлов, аудит, уведомления и реальный workflow согласования не реализованы. Статус «На согласовании» локальный. Поля подписи и «М.П.» визуальные и не являются юридически значимой электронной подписью или печатью.

Для production потребуются backend/API, общая БД, TFE Identity, серверные права доступа, реальный workflow, файловое хранилище, аудит, резервное копирование и при необходимости юридически корректная интеграция электронной подписи.
